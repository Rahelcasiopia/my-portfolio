# Rachel Nigussie – Portfolio (Next.js)

Next.js 15 (App Router) + React 19. No other dependencies.

## Run it
```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Edit your content
Everything (name, links, skills, projects, education, email, phone) is in `data/site.js`.
Colours and fonts are CSS variables at the top of `app/globals.css`.

## Deploy
Push to GitHub and import the repo on https://vercel.com (free). Zero configuration.
